# Полный примитивный квантово-марковский генератор

> Status: mature
> Type: question
> Updated: 2026-08-29

## Summary

Linking-, gauge- и cross-arrow формы Дирихле собраны в одну полугруппу на
`M11(C) direct_sum M10(C)`. Неподвижная алгебра стала скалярной, поэтому
единый процесс примитивен. Результат устойчив при всех проверенных
положительных весах, но спектральная щель и относительные скорости не
фиксированы.

## Problem

Проверить, образуют ли отдельно построенные части один вполне положительный
процесс с единственным стационарным состоянием, либо между ними сохраняется
скрытая суперселекция.

## Search for solution

- Собран генератор из linking-, `SU3`-, `SU2`-, `U1`-, `QLYR`- и
  `XLdR`-слагаемых.
- Построен общий сертификат Линдблада из 25 самосопряжённых jump-операторов.
- Вычислены полное ядро, спектральная щель и тесты удаления каждого
  слагаемого.
- Выполнены 48 сканов независимых положительных весов `1e-3..1e3`.
- Проверена следовая detailed balance каждого слагаемого отдельно.

## Expected result

Cross-часть должна снять остаточную `C²`, сохранив полную положительность и
endpoint-алгебру. Количественное замыкание требует, чтобы дополнительное
условие выбирало относительные скорости.

## Compliance check

- Матрица ограничения имеет размер `221`; все 25 jump-операторов
  самосопряжены.
- Неподвижная алгебра равна `C I21`, единичная щель —
  `0.1112337884`, максимальная скорость — `10.4919129635`.
- Без cross-части размер ядра равен двум; каждая полная cross-семья отдельно
  уже закрывает прежнюю двухсекторность.
- Все 48 положительно взвешенных сборок имеют одномерное ядро.
- Следовая detailed balance выполняется для любого набора положительных
  весов и потому их не выбирает.
- Два запуска дали одинаковый SHA-256
  `91263a344100b92ad94b5082aa9812b020693d2e34ffbac71e605f317c10ecc6`.

## Key Points

- Качественная сшивка полного операторного процесса завершена.
- Единственное верное стационарное состояние — `I21/21`.
- Получен универсальный класс примитивных полугрупп, а не единственная
  количественная динамика.
- Следующий тест должен использовать нетривиальное KMS-состояние; обычный
  след уже доказанно не является селектором скоростей.
- [[version8-kms-nontracial-relative-rate-selector-gate]] показывает, что
  внутри текущего унитального примитивного генератора такой селектор
  невозможен: единственное инвариантное состояние уже является следовым.
