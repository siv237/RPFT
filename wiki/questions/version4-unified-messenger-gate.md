## Representation Result

Separate SU(5) packages require `10+bar10`, `5+bar5` and a singlet pair. A
single SO(10)-type `16+bar16` vectorlike package contains all four Dirac
endpoint representation types.

The neutral-plus-hidden-charged chain needs two such vectorlike pairs, or 64
Weyl messenger states before path replication.

## Gauge Running Result

For a chiral 16, `C1=C2=C3=2`. A vectorlike `16+bar16` shifts all one-loop
beta coefficients by `8/3`. Complete degenerate multiplets therefore leave
all beta-function differences and pairwise crossing scales unchanged.

## Verdict

The unified package solves representation coverage but cannot repair the
minimal gauge mismatch. Relative running requires component splitting inside
complete SU(5) pieces, incomplete multiplets or a new high-scale algebra.
