# Коротковременное корреляционное ядро как селектор скоростей

> Status: mature
> Type: question
> Updated: 2026-08-29

## Summary

Полная матрица процесса на `M11(C) direct_sum M10(C)` при известном времени
точно восстанавливает все шесть интенсивностей генератора. Без калибровки
времени восстанавливаются пять относительных весов, но не общий масштаб.
Этот положительный результат пока условен: независимое физическое endpoint-
ядро в проекте не найдено.

## Problem

Проверить, снимает ли коротковременный наклон полного корреляционного ядра
пять свобод Тома VIII, оставшихся после цепного KMS-селектора.

## Search for solution

- Построена полная `221 x 221` матрица шести семейных генераторов.
- Проверены логарифмическая реконструкция и производная при нулевом времени.
- Отдельно исследована неизвестная калибровка времени.
- Проверена потеря быстрых мод при большом времени и конечной точности.
- Просмотрены ранняя TOE-формула ядра и гейт реконструкции локальности.

## Expected result

Независимо заданное полное ядро должно однозначно определять относительные
интенсивности; иначе корреляционный маршрут не снимает конус метрик.

## Compliance check

- Ранг дизайна шести генераторов равен `6`, число обусловленности `4.33773`.
- Максимальная ошибка точного восстановления весов равна `5.32e-14`.
- При неизвестном времени нормированные относительные веса восстановлены.
- Ошибка конечной разности падает с `0.2152` до `0.00261`.
- В жёстком тесте 163 быстрые моды ушли ниже машинной точности.
- Независимая физическая матрица `C_tau` на endpoint-алгебре не найдена.
- Два запуска дали одинаковый SHA-256
  `c2fe545d6cf563e76e2361c7ed4159d90614e3f175466aa48ab1b429a8eb8996`.

## Key Points

- Полное ядро действительно содержит недостающие относительные скорости.
- Неизвестная единица времени не мешает отношениям, но скрывает общий масштаб.
- Ядро, вычисленное из уже выбранного генератора, не может служить его
  независимым объяснением.
- Следующая задача — вывести физическое ядро из родительского действия или
  состояния до выбора скоростей.
