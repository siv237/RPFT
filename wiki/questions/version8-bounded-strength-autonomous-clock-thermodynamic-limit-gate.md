# Термодинамическая ресурсная граница автономных квантовых часов

> Status: mature
> Type: question
> Updated: 2026-08-30

## Summary

Экспоненциально точные конечные квазиидеальные часы позволяют приблизить
двухслойный конвейер на любом конечном кольце. Телескопическая оценка даёт
глобальную ошибку не более `2 L A exp(-c d)`, поэтому для ошибки `delta`
достаточно `d >= log(2 A L/delta)/c`. При линейном энергетическом росте
часов это требует энергии порядка `log(L/delta)`.

Фиксированная размерность часов не даёт имеющемуся сертификату равномерности
по глобальной норме канала. Для наблюдаемых с конечным носителем при
фиксированном времени число действий в причинном конусе не зависит от
полного объёма, поэтому локальный термодинамический предел остаётся
допустимым.

## Problem

Проверить, может ли часовой носитель ограниченной энергии автономно
реализовать конвейер при переходе к бесконечной цепи.

## Search for solution

- Использована экспоненциальная оценка ошибки конечных квазиидеальных часов.
- Ошибка композиции ограничена телескопической оценкой нормы каналов.
- Точно обращена зависимость ошибки от размерности часов.
- Разделены глобальная норма полного канала и локальная сходимость
  наблюдаемых внутри конечного причинного конуса.
- Учтено существование стационарных ближайше-соседних гамильтоновых
  вычислителей, поэтому универсальный запрет не заявляется.

## Expected result

Конечный объём допускает автономное приближение произвольной точности.
Глобальный термодинамический контроль требует растущего часового ресурса;
локальная сходимость может существовать при фиксированных конечных часах.
Точный возврат часов и размерная длительность такта остаются открытыми.

## Compliance check

- `epsilon_global <= 2 L A exp(-c d)`;
- `d >= log(2 A L/delta)/c` достаточно для ошибки `delta`;
- при `E_d=O(d)` достаточная энергия равна `O(log(L/delta))`;
- фиксированный `d` не сертифицирует глобальную равномерность;
- локальная оценка `N_loc A exp(-c d)` независима от полного объёма;
- LCF-обязательства включены в реестр.
