# Radial Pfaffian Hessian
> Status: working
> Type: question
> Updated: 2026-08-15

Pfaffian пересчитан для self-adjoint connector `z=r exp(i theta)`. Корректный
determinant обращается в нуль при `r -> 0`; прежнее выражение с `z^-3` нельзя
было продолжать вне unit circle.

Bosonic и Pfaffian Hessians в координатах `(log r, theta)` диагональны.
Radial mode не регулирует orientation на quadratic level. При `lambda=1`
глобальные minima имеют `theta=0`.

CP bifurcation потребовала бы `lambda < 0.056684` для reduced measure или
`lambda < 0.028906` для full KO6, что нельзя выбирать по CKM.
