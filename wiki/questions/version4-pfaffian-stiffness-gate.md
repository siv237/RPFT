# Pfaffian stiffness gate
> Status: working
> Type: question
> Updated: 2026-08-15

Pfaffian modulus имеет curvature `2/9` для reduced measure и `4/9` для full
KO6 modulus. Это соответствует local couplings `g=9/2` и `g=9/4`, оба выше
critical `g_c=1.47996`.

Точный periodic functional даёт ненулевые orientation minima. Однако reduced
branch почти переставляет первые поколения, а full branch создаёт слишком
большое смешивание во всех плоскостях. Blind flavour не закрыт.

Quadratic Hessian запрещено экстраполировать до больших orientation fields;
только exact periodic potential считается допустимым.
