# Version IV.SM Relative Krajewski Star Gate
> Status: working
> Type: question
> Updated: 2026-08-15

The state algebra splits M3 into four corners of dimensions 1, 2, 2 and 4.
Star closure, anchor connectivity and exclusion of independent complement
dynamics select one unique five-dimensional relative Krajewski star. Its
projection is endpoint inclusion--exclusion. This conditionally derives the
support axiom, but gauge--family factorization still produces only two family
textures for the four observed Yukawa sectors.
