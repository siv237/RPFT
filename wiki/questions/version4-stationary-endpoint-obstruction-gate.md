## Вопрос

Может ли требуемый nonlinear flavour endpoint быть stationary solution уже
существующего spectral parent action?

## Cross-tome inputs

- Том III фиксирует normalized quartic coefficient `lambda = 1`.
- Radial Pfaffian gate требует `lambda < 0.056684` в reduced branch.
- Full KO6 threshold равен `lambda < 0.028906`.

## Результат

Spectral value превышает thresholds в `17.64` и `34.59` раза. Angular
curvatures остаются положительными: `7.54653` и `7.76875`.

## Вердикт

В текущем CP-even parent action искомой stationary flavour branch нет. Нужен
либо выведенный CP-odd mixed invariant, либо независимое изменение quartic
normalization. Дальнейший подбор endpoint functions запрещён.
