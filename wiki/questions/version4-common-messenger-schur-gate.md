# Common messenger Schur gate
> Status: working
> Type: question
> Updated: 2026-08-15

## Вопрос

Может ли один общий двухканальный messenger propagator превратить четыре
канонических ребра sector torsor в реалистические массы и CKM без четырёх
независимых Yukawa-матриц?

## Конструкция

Используется общий тяжёлый блок

`M(t) = ((t I, i I), (-i I, t I))`, `t > 1`,

и два инцидентных edge operators каждого сектора. Schur complement содержит
фиксированный комплексный коммутатор. Полностью перебраны 16 глобальных
знаковых коциклов; только `t` обучается по четырём quark mass ratios.

## Результат

Лучший кандидат имеет `t = 1624.1449`, но предсказывает одинаковые
нормированные up/down-спектры `(0.00123240, 0.00123347, 1)`. CKM практически
единична, а Jarlskog равен примерно `1.96e-29`.

## Вердикт

Ветка закрыта. Общий центральный propagator слишком симметричен. Следующая
допустимая конструкция должна выводить sector-relative нецентральную часть
propagator из representation labels или единого boundary order parameter.
