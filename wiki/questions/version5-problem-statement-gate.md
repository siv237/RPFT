# Version V problem statement gate

> Status: working
> Type: question
> Updated: 2026-08-15

## Problem

Version IV retained a reproducible mathematical core but closed with
`R_sci=4/10` and `N_closed_physical=0`. Its repeated obstruction was the
absence of one prior architecture fixing the state space, measure, vacuum,
relative sector weights, gauge quotient, counterterms and observable map.

## New object

Tome V defines a parent architecture

`P=(A,H,D,J,gamma; carrier class, state space, measure; functional, quotient, readout)`.

This is intentionally broader than a spectral triple because the previous
program showed that spectrum alone does not determine ensembles, topology
weights, finite counterterms or the physical quotient.

## Admissible entry classes

1. Corrected TOE 6.5 joint state/carrier variation.
2. Boundary-source/Wilson--defect path integral or superconnection.
3. Genuinely new finite geometry: higher-rank/noncommuting Pati--Salam
   carrier or a family--defect geometry with a derived relative channel.

## Gate V.0

Before phenomenology, each class may submit one short architecture dossier
with a fundamental object, one coefficient-free functional, a complete
measure/statistics/counterterm ledger, one decisive Hessian/rank/sign test
and two reserved blind endpoints. One class is then frozen; the others may
not donate weights or fields to it.

## Stop rule

If no class fixes its primary functional and physical Hessian before
observed inputs, Tome V stops at an obstruction classification and does not
open new mass, CKM, coupling or absolute-scale fits.

## Next gate

Create the comparative Gate V.0 architecture specification and freeze the
first binary selection criteria for the three dossiers.
