# Root Mass Condensate Trilemma Gate

> Status: homogeneous Majorana branch closed negatively
> Date: 2026-08-06

## Question

Can one order-four sterile root simultaneously support a scalar invariant Majorana vertex and a uniform parallel pairing condensate?

## Results

- The sterile root has phase `r=+i`, so the bilinear `N_c N_c` has phase `r^2=-1`.
- Scalar Yukawa invariance requires pairing-field phase `phi=-1`.
- A uniform parallel nonzero condensate requires `phi=+1`.
- The ordinary charge-minus-two field preserves the Yukawa vertex but fails the uniform-vacuum condition.
- The ambient-torsion-twisted field satisfies the uniform-vacuum condition but makes the scalar Yukawa vertex torsion-odd.
- Adding a torsion-odd Yukawa spurion restores the vertex only by moving the obstruction into a new defect or chosen trivialization.

## Verdict

The order-four root, scalar linear Majorana invariance, and a homogeneous parallel condensate form a strict trilemma. The surviving branch is necessarily a nonuniform class-D defect texture, not a homogeneous B-L Majorana mass.
