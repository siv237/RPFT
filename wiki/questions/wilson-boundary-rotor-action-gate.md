# Wilson Boundary Rotor Action Gate
> Status: working
> Type: question

## Result

The nonlinear part of the Wilson gap functional can be generated by stable
boundary rotors in a fixed-charge ensemble.

The exact coefficients require the minimal arithmetic data

`N=16`, `d=3`, `q^2=3`.

## Canonical Representation

No irreducible `SU2` representation has Casimir three. Among reducible
dimension-16 representations with average Casimir three, the unique solution
without singlets and with only half-integer spins is

`2 V_(1/2) + 3 V_(3/2)`.

It simultaneously gives:

- total dimension 16;
- normalized average Casimir 3;
- logarithmic coefficient `8/3`;
- inverse coefficient `8`;
- minus-one action of the center on every block, hence the half-shift.
