# Том VI: совместный квадрупольно-тетраэдрический вакуум

> Status: working
> Type: question
> Updated: 2026-08-20

## Краткий вывод

Построена смешанная матричная кривизна из уже выведенных полей `Q` и
`T`. Она без нового относительного коэффициента привязывает проективную
ось `Q` к одной из четырёх осей тетраэдра. Полный физический гессиан
строго положителен, все три компоненты одной семейной связности массивны,
а остаточная группа равна `Z3`.

## Смешанная кривизна

Для спектральной щели `Delta=a*-b*` проективное чтение имеет вид
`P_Q=I3/3+Q/Delta`. Композиция с тетраэдрическим тензором даёт
`w_i=T_ijk(P_Q)_jk`. На каноническом тетраэдре и его вершине
`w=(8/9)n`, поэтому

`F_QT=w w^T-(64/81)P_Q`, `V_QT=Tr(F_QT^2)/3`.

Число `64/81` фиксируется геометрией тетраэдра; нового параметра нет.
Норма смешанного блока гессиана равна `1.761249...`, то есть это настоящее
сцепление двух полей.

## Вакуум и гессиан

- выровненный вакуум имеет нулевой потенциал с остатком `9.5e-16`;
- изотропная ветвь `Q=0`, `T=T*` поднята на `4096/59049`;
- без сцепления есть пять нулей, после сцепления — только три направления
  общей калибровочной орбиты;
- после факторизации по ней все девять физических собственных значений
  положительны; минимум равен `1.214733...`;
- отрицательных и дополнительных нулевых физических мод нет.

## Калибровочный сектор

Совместная массовая матрица связности имеет спектр
`{14.222222...,15.729938...^(2)}`. Непрерывный стабилизатор исчезает.
Из двенадцати вращений `A4` выбранную проективную ось сохраняют три,
поэтому вакуумное многообразие равно `SO(3)/Z3`.
