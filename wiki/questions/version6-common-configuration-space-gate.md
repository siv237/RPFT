# Version VI: общее пространство конфигураций

> Status: working
> Type: question
> Updated: 2026-08-19

## Summary

Первый гейт Тома VI различает отдельные ориентированные индексы, обычный
индекс полной Real-пары и её ненулевой `KO6`-класс. Для сбалансированной
пары построен явный конечномерный обменный мост ранга `15`, делающий
оператор обратимым и при единичной связи унитарным.

## Main Result

Для

`T_0 = diag(S tensor I_15, S* tensor I_15)`

вводится мост `K`, отображающий ядро второй ветви на коядро первой. Семейство

`T_lambda = T_0 + lambda K`

обратимо при любом `lambda > 0`, а `T_1` унитарно. Поэтому устранение явных
нулевых мод нейтральной пары не требует выхода из пространства
фредгольмовых операторов.

## Correction to the Previous Reading

- Нижняя граница `1/7` строга для каждой ориентированной ветви и для
  пространства, запрещающего межветвевое смешивание.
- Она не является инвариантом суммы `dim ker + dim coker` во всём
  обменном пространстве: мост удаляет оба дефекта.
- Из обратимости не следует исчезновение ненулевого `KO6`-класса:
  обратимый фредгольмов представитель не обязан быть вырожденным нулевым
  циклом. Сохранение проектного Real-класса именно этим мостом остаётся
  условным до проверки полного `J` и Clifford-действия.

## Reopened Mechanism

Нужно различать создание класса из нулевого вакуума и проявление уже
существующего скрытого класса. Во втором случае локальные дефекты появляются
при выключении межветвевого моста без изменения общего `KO6`-класса.

## Open Point

Неизвестно, является ли мост допустимой физической одноформой текущего
родителя и сохраняет ли он полный `J`, Clifford-структуру, gauge- и
BV/BRST-фактор. Это следующий решающий гейт.

Следующий аудит дал частичный ответ: базовый `J` совместим, но в
замороженном модуле одноформ `H15` мост отсутствует. См.
[[version6-exchange-bridge-parent-admissibility-gate]].
