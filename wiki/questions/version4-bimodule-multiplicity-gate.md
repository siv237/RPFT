# Version IV.SM Bimodule Multiplicity Gate
> Status: working
> Type: question
> Updated: 2026-08-15

## Result

An exhaustive search over 15,625 multiplicity vectors was performed for the
restricted one-generation edge menu.

- Yukawa completeness relates the right singlets to the left doublets.
- The mixed weak anomaly forces equal quark and lepton generation
  multiplicities.
- The minimal Dirac-neutrino solution is one copy of every multiplet and has
  16 complex particle states.
- Without a right-handed neutrino the minimal solution has 15 states.
- Every higher solution is a common generation replication by an integer
  `g`.

## Limitation

The generation atom is fixed inside the restricted menu, but the observed
number `g=3` is not selected.
