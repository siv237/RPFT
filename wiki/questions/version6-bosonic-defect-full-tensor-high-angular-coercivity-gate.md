# Том VI: полный высокоугловой хвост тензорного вихря

> Status: working
> Type: question
> Updated: 2026-08-20

## Краткий вывод

Все угловые метки полного калиброванного оператора `Q+T+B` покрыты для трёх
скрученных характеров `Z3`.

- низкое окно `|j|<=3` перепроверено плотным алгебраическим решателем;
- прямой мост `4<=|j|<=139` не содержит отрицательных уровней;
- минимум моста равен `3.77339594` при `|j|=4` и далее строго возрастает;
- для `|j|>=140` действует положительная возрастающая оценка Гершгорина;
- запас на пороге равен `1.21178043`, его производная — `0.12813910`.

После удаления переносной пары отрицательных внутренних мод не осталось.
Следовательно, полный поперечный оператор прямой стационарной нити линейно
неотрицателен для всех угловых меток.

## Открытая точность

Самый низкий внутренний блок на сетке `80` равен `3.61877141` и расположен в
сопряжённой паре `(c,j)=(1,1),(-1,-1)`. Его точный континуальный предел ещё
нужно вычислить. Это не мешает знаковому сертификату, но требуется для
масштаба первого внутреннего возбуждения.
