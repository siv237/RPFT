# Обратный индекс дотомовых формул

> Status: working
> Type: source
> Updated: 2026-08-25

## Summary

Это корневая страница механического индекса блочных формул, найденных
в дотомовом корпусе RPFT. Каждая запись хранит точный путь, номера
строк и исходный LaTeX-блок. Индекс не присваивает формуле доказательный
статус: для этого служат [[pre-tome-formula-genealogy]],
[[global-formula-atlas]] и [[global-theorem-and-no-go-ledger]].

## Воспроизводимый итог

| Показатель | Значение |

| файлов с блочными формулами | 78 |

Прежнее число `969` было заявлено в навигации, но пустой файл не сохранил
ни сам перечень, ни правило его подсчёта. Повторяемый парсер даёт `950`:
он считает парные `$$...$$`, `\[...\]` и внешние окружения
`equation`, `align`, `gather`, `multline`, `displaymath`, `eqnarray` и их
звёздные варианты. Число `969` не используется без восстановления иного
явного правила извлечения.

- зеркала `s2t/RPFT-main/` не считаются независимыми вхождениями;
- канонический хронологический источник — `архив-2025-2026/`;
