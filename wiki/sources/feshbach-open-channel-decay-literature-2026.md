# Фешбаховское исключение и распад через открытый канал

> Status: working
> Type: source
> Updated: 2026-08-21

## Summary

Фешбаховское исключение даёт конечную мнимую часть эффективного оператора
только при ненулевом форм-факторе в открытый спектральный канал. Для
дискретной динамики необходимо вычислять спектральную меру конкретного
локализованного направления; одного наличия радиационной зоны
недостаточно.

## Key Points

- Feshbach (1958) выводит эффективный оператор после исключения открытых
  каналов.
- Fano (1961) связывает дискретное состояние с континуумом и получает
  резонансный профиль из интерференции конфигураций.
- Для дискретного времени роль энергии играет флоке-множитель, а
  спектральная плотность должна вычисляться на его резонансном значении.
- Bisio--Mosco--Perinotti строят теорию рассеяния и возмущений для
  дискретно-временной динамики.
- В компакттонном аудите форм-фактор оказался ненулевым только для одной
  вещественной квадратуры. Это породило исходящие пакеты, но не истощение
  характерного источника; следовательно, золотое правило описало
  радиационную нестабильность, а не захват.
