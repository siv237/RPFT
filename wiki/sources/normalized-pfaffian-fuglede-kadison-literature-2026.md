# Нормированный детерминант и пфаффиан конечной геометрии

> Status: working
> Type: source
> Updated: 2026-08-19

## Summary

Детерминант Фугледе--Кадисона переводит нормированный след в интенсивный
логарифм детерминанта через `log Delta_tau(A)=tau(log|A|)`. Вещественный
фермионный интеграл при допустимой KO-степени даёт Pfaffian, то есть
квадратный корень обычного детерминанта антисимметричной формы. Эти два
утверждения различны: стандартный березинский интеграл сам по себе не
делит `log Pf` на размерность носителя.

## Project Consequence

Следовые отношения `30/300`, `15/300`, `15/210` математически дают
коэффициенты `1/10`, `1/20`, `1/14` только для нормированной интенсивной
свободной энергии. После построения product-KO2 обычный пфаффиан
пятнадцатикратного семейного блока имеет показатель `15`. Поэтому
прежняя возможность понижена: нужен общий принцип нормирования всей
свободной энергии, а не только фермионного члена.
