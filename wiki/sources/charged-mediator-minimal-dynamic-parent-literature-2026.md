# Литература по минимальному динамическому parent charged mediator

> Status: working
> Type: source
> Updated: 2026-08-31

## Summary

Предел повторных взаимодействий обосновывает присоединение ортогональных
ancilla-выходов к GKSL-генератору, а индексная теория одномерных квантовых
автоматов отделяет точный тёплиц-сдвиг от локальной гамильтоновой эволюции.

## Key Points

- Ортогональные состояния выхода среды дают независимые jump-каналы во
  втором вакуумном моменте.
- Fresh-ancilla chain реализует итерации одного канала одним глобальным
  Флоке-оператором.
- Локальный projector-parent может выбирать product-vacuum, не порождая
  при этом транспорт ячеек.
- Одноклеточный сдвиг `d`-мерной цепи имеет GNVW-index `d`; для новой
  ячейки индекс равен `45`.
