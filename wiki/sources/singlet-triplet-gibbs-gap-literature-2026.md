# Gibbs-щель синглета и триплета: литературная опора

> Status: working
> Type: source
> Updated: 2026-08-30

## Summary

Первичная литература разделяет три логических слоя. Максимум энтропии
строит наименее предвзятое состояние только после задания ограничений;
Gibbs-вариационный принцип даёт уникальный минимум только при заданном
гамильтониане; квантовый detailed balance определяется относительно уже
выбранного верного инвариантного состояния. Поэтому ни один из этих
принципов сам по себе не создаёт singlet--triplet энергетическую щель.

## Project Reading

Для спектрального типа `1+3` аддитивный нуль энергии сокращается, а
равновесное состояние зависит только от `theta=beta Delta`. Кратность три
входит как статистический множитель:
`p=1/(1+3 exp(-theta))`. Значения `beta` и `Delta` отдельно не
идентифицируются по равновесному весу; скорость релаксации дополнительно
требует корреляционной функции или спектральной плотности среды.

Классификация конечных спектральных троек фиксирует матричные блоки,
представления и стрелки, но не добавляет тепловой контраст между
неэквивалентными центральными секторами. Поэтому диаграмматическая
кратность `1+3` определяет коэффициент `3` в статистической сумме, а не
значение `theta`.
