# Источники parent-action origin конечного endpoint-модуля

> Status: working
> Type: source
> Updated: 2026-08-31

## Summary

Первичные источники разделяют фиксированные данные конечной спектральной
тройки и вариацию оператора Дирака. Классификационные кратности задают
компоненту finite geometry; обычное спектральное действие само по себе не
задаёт сумму или переход между различными диаграммами.

## Key Points

- Спектральное действие определено после задания `(A,H,D)`.
- В простом динамическом spectral-triple примере фазовое пространство
  образуют операторы `D`, совместимые с фиксированными `A,H`.
- Диаграммы Краевского кодируют дискретные representation multiplicities.
- Projector-parent на `H24` является conditional construction, а не
  происхождением ambient module.
