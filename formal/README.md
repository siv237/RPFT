# Будущий Lean-слой

Эта папка зарезервирована для реально проверяемых формализаций. Сейчас в ней
нет Lean-проекта и нет заявлений о машинно проверенном доказательстве.

Перед добавлением первой реализации нужно зафиксировать:

1. версии Lean, Lake и mathlib;
2. воспроизводимый `lake build`;
3. раздельные challenge- и solution-модули;
4. запрет `sorry` и аудит используемых аксиом;
5. `formalization.yaml` с точным обычным описанием результата;
6. конфигурацию Comparator и автоматическую проверку в CI.

Исходные задания лежат в `formalization_candidates/`. Реализация не должна
расширять их физический смысл без предварительного обновления и повторной
заморозки спецификации.
