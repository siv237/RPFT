# План формализации и проверки

1. Формализовать `Sym3(R)` и rank-one Real projector.
2. Проверить спектральные projector identities одноосного Hamiltonian.
3. Доказать инвариантность ground projector при `h -> a h+bI`, `a>0`.
4. Вычислить determinant, rank и purity конечного Gibbs-state.
5. Проверить нулетемпературный предел и trace distance.
6. Разделить direction, cooling и absolute-gap данные.
