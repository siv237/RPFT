# Что не утверждается

- Не утверждается физическая допустимость произвольного `deltaKK`; свидетели
  фиксируют только пробел спецификации полного подъёма.
- `B0` не отождествляется с коэффициентом невыбранной компактификации.
- Безразмерное RG-отношение не объявляется абсолютной массой.
- Не строится карта `c0` и не выводится барионная масса.
