# Определения

В стандартном базисе:

```text
U4 = [[0,-1],[1,0]],
U4^2 = -I,
U4^4 = I.
```

Спектральные проекторы:

```text
P_{±i} = (1/4) sum_{n=0}^3 (±i)^(-n) U4^n.
```

Для внутренней кратности проект расширяется как `U4 tensor I` и
`P_{±i} tensor I`; доказательство не должно зависеть от конкретной конечной
кратности.

Характерные веса определяются квадратичной формой ортогональных проекторов.
Функционал `D_chi` — диагностический инвариант, а не член действия.
