# Theorem

> Status: spec-frozen

A fixed finite spectral-triple parent cannot produce the multiplicity jump
`(0,0,2)->(1,1,3)`. An unseeded rank-three projector parent on `H24` has
minimum manifold `Gr_C(3,24)` of real dimension `126`; a seed selecting the
required projector is target-loaded because `P_E=(I-C_E)/2`, and the
increment projector selects an axis inside the irreducible family triplet.
