# План формализации и проверки

1. Вычислить семейный квадратичный оператор Казимира на `1+3`.
2. Центрировать grading и Казимир и доказать их равенство.
3. Вычислить ранг порождённой центральной алгебры.
4. Построить положительные свидетели обоих знаков щели.
5. Проверить свободу Casimir-полинома и слепоту квадратичного действия.
