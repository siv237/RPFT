# Определения

Для положительных `massSq`, `couplingSq`, `q` и `z >= 0`:

```text
parent(phi,J) = (z+massSq) phi^2/2 - coupling phi J
phiStar       = coupling J/(z+massSq)
form(massSq,z) = massSq/(z+massSq)
scaledForm(q,massSq,z) = q*massSq/(z+q*massSq).
```

Здесь `couplingSq = coupling^2`. Статическое сопоставление задаётся
отношением `couplingSq/massSq = lambda`.
