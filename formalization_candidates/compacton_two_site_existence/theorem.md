# Двухузловое собственное состояние дискретного шага

> Status: candidate

Пусть сбалансированный внутренний вектор `v = (ell,e)` удовлетворяет
`||ell||^2 = |e|^2 = 1/4`, а активная частота равна `a = 1/4`. Для каждого
натурального `m` положим

```text
kappa_m = 2 (2m+1) pi,
s_m = (-1)^m.
```

Определим состояние с поддержкой ровно на двух соседних узлах:

```text
Psi_0 = |-> tensor v,
Psi_1 = |+> tensor (i s_m v),
Psi_n = 0 при n != 0,1.
```

После точного определения локальной монеты и условного сдвига из первичного
гейта требуется доказать

```text
F_{kappa_m}(Psi) = i Psi.
```

Отдельная элементарная часть контракта:

```text
cos(kappa/4) = 0
```

для положительных `kappa` эквивалентно указанному дискретному ряду.
