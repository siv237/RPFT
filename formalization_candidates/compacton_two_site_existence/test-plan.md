# План формализации и проверки

1. Выписать из гейта полное определение нелинейной монеты и сдвига.
2. Выбрать конечноподдержанное представление состояния, удобное для Lean.
3. Доказать нормировку двухузлового профиля.
4. Доказать тригонометрическую классификацию `cos(kappa/4)=0`.
5. Вычислить действие монеты на двух активных узлах.
6. Вычислить условный сдвиг и получить `F Psi = i Psi` для любого `m`.
7. Отдельно вывести период четыре из собственного значения `i`.
8. Проверить отсутствие предположения, эквивалентного самому заключению.
