# План формализации и проверки

1. Ввести структуру `AnchorCandidate`.
2. Определить предикат прохождения четырёх условий.
3. Внести шесть записей как конечный список.
4. Вычислить `map passes candidates`.
5. Доказать нулевое число успешных записей через `decide`.
6. Проверить отсутствие `sorry` и новых `axiom`.
