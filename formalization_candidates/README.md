# Кандидаты на формальную верификацию

Эта папка переводит строгие формулы проекта из LaTeX-гейтов в короткие,
однозначные технические задания для будущей формализации на Lean.
Markdown-файл здесь **не является доказательством** и не означает, что
результат уже проверен Lean или принят Palomar.

## Статусы

- `candidate` — результат выбран, но контракт ещё может меняться;
- `spec-frozen` — определения, предпосылки, утверждение и границы зафиксированы;
- `lean-draft` — реализация начата в `formal/`, но не прошла все проверки;
- `lean-verified` — локальная сборка Lean проходит без недопустимых аксиом;
- `palomar-ready` — подготовлены challenge, solution, метаданные и проверка
  Comparator.

## Состав задания

Каждый кандидат содержит:

- `theorem.md` — точное утверждение обычным языком;
- `definitions.md` — все используемые объекты и формулы;
- `assumptions.md` — явные области определения и предпосылки;
- `source-map.md` — связь с гейтом, результатом и страницей вики;
- `nonclaims.md` — утверждения, которые кандидат не доказывает;
- `test-plan.md` — план разбиения на проверяемые леммы.

## Переход к Lean

Реализация создаётся отдельно в `formal/`. Кандидат повышается до
`lean-verified` только после воспроизводимой сборки фиксированной версией Lean
и mathlib. Для подготовки к Palomar дополнительно потребуются формальный
challenge, solution module, `formalization.yaml` и конфигурация Comparator.
