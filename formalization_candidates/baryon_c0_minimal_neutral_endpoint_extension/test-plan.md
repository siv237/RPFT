# План формализации и проверки

1. Ввести `H23`, проекторы и matrix unit.
2. Доказать минимальность двух нейтральных линий.
3. Проверить grading, gauge и Real conditions.
4. Доказать три commutator identities.
5. Проверить линейную независимость расширенного frame.
6. Вычислить trace Gram block.
7. Собрать без `sorry` и новых `axiom`.
