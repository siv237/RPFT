# Неединственность нормированного положительного нелокального ядра

> Status: spec-frozen

Для функций из `definitions.md` требуется доказать:

```text
f1(0) = f2(0) = 1,
f2(z) - f1(z) = 3z / (2(z+1)(z+4)),
0 < z -> f1(z) < f2(z),
f1'(0) = -1,
f2'(0) = -5/8.
```

Обе функции имеют положительные спектральные представления:

```text
f1: (r,m2) = [(1,1)],
f2: (r,m2) = [(1/2,1),(2,4)].
```

Для `0 <= t <= 1` функция `ft` положительна и `ft(0)=1`. Поэтому
статическая нормировка и положительность не выбирают единственный
форм-фактор. Если `W != 0` и `lambda != 0`, то операторы
`K(f1,z)` и `K(f2,z)` совпадают при `z=0`, но различны при `z>0`.
