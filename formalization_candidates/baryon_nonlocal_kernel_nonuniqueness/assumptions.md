# Предпосылки

- `z`, `t` вещественны, `0 <= z` и `0 <= t <= 1`.
- `W` — ненулевой линейный оператор над вещественным или комплексным
  конечномерным пространством.
- Для операторного короллария `lambda != 0`.
- Самосопряжённость и симметрии `W` являются отдельными предпосылками;
  рациональная часть теоремы от них не зависит.
- Знаменатели `z+1` и `z+4` положительны на выбранной области.
