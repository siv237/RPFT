# План формализации и проверки

1. Ввести `f1`, `f2`, `ft` как функции `Real -> Real`.
2. Доказать положительность знаменателей при `0 <= z`.
3. Нормализовать разность `f2-f1` оператором `ring_nf` или `field_simp`.
4. Доказать строгий знак разности при `0 < z`.
5. Вычислить значения и производные в нуле без численных приближений.
6. Проверить два конечных положительных спектральных разложения.
7. Доказать положительность и нормировку выпуклого семейства `ft`.
8. Добавить королларий для скалярного умножения ненулевого оператора.
9. Проверить сборку без `sorry`, новых `axiom` и чисел с плавающей точкой.
