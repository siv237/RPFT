# Определения

Работа ведётся над рациональными функциями переменной `z >= 0`:

```text
f1(z) = 1/(z+1)
f2(z) = 1/(2(z+1)) + 2/(z+4)
ft(z) = (1-t) f1(z) + t f2(z),  0 <= t <= 1.
```

Для ненулевого линейного оператора `W` и скаляра `lambda` определяется

```text
K(f,z) = lambda * f(z) * W.
```

Положительное спектральное представление означает конечную сумму
`sum_j r_j/(z+m_j^2)` с `r_j > 0` и `m_j^2 > 0`.
