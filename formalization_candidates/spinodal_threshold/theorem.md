# Точный спинодальный порог одноосной семьи

> Status: spec-frozen

Для функций из `definitions.md` и любого вещественного `beta` в точке
`a = 1/3` выполняется

```text
F_beta''(1/3) = 9/2 - 3 beta/7.
```

Следовательно:

```text
F_beta''(1/3) = 0  <->  beta = 21/2,
F_beta''(1/3) > 0  <->  beta < 21/2,
F_beta''(1/3) < 0  <->  21/2 < beta.
```

Формальный контракт ограничен тождеством для второй производной и знаком
кривизны. Термин «спинодальный порог» является интерпретацией этого точного
одномерного результата.
