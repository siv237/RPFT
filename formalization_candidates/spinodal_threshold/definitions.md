# Определения

Работа ведётся над вещественными числами при `0 < a < 1`:

```text
S(a)  = a log(a) + (1-a) log((1-a)/2)
q2(a) = (3a^2 - 2a + 1)/2
q3(a) = (3a^3 + 3a^2 - 3a + 1)/4
E(a)  = (2/7) (1 - q2(a)^2/q3(a)) + 1 - q2(a)
F_beta(a) = S(a) + beta E(a)
```

Точка изотропного состояния: `a_iso = 1/3`.
Точный кандидатный порог: `beta_sp = 21/2`.
