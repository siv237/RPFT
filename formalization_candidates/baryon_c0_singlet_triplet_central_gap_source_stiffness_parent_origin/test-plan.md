# План формализации и проверки

1. Проверить нулевое ограничение старого родителя.
2. Вычислить первые и вторые вариации следовых моментов степеней `1..6`.
3. Доказать общий нулевой источник на скалярном фоне.
4. Вычислить grading- и Casimir-маркированные линейные отклики.
5. Построить условную карту `(a2,g)->(m²,j)`.
6. Проверить круговость нескалярного фона и тип шумового гессиана.
