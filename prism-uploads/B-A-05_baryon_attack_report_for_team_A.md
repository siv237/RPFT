## 0. Резюме для принимающего решение

За отчётный период Задача №1 («закрыть барионы») продвинута **двумя пакетами теоремного уровня**; оба доведены до машинных сертификатов и подтверждены повторными прогонами.

**Пакет 1 — B-A-04: метрическая единственность фона суперкривизны.**
В классе посылок (P1)–(P3) чётный фон **единствен**: M = ±(μ/2)I₂₁. Вместе с no-go Команды A по нецентральным нечётным фонам **классификация однофоновых сдвинутых кривизн полна**: единственный источник нарушения чётности — центральный фон; кубическая проекция на d_abc исчерпывается вершиной 2μ·d_abc, то есть **λ₃ = 2μ** с единственным остаточным freedom'ом — одним скалярным масштабом μ. Nogocriterion: теорема фиксирует **форму** фона, а не **число** μ — абсолютный масштаб не выведен и внешен для центрированных данных кадра.

**Пакет 2 — B-GATE-DERIV-01: атака гейта `derivative_cubic_vertex_to_six_point_kernel_or_stop`.**
Вердикт: **честный STOP производной ветви** — по трём независимым режущим фактам:

1. **Нулеимпульсный предел.** Все допустимые производные кубические каналы линейны по импульсам, поэтому K₆(0) = 0, тогда как требуемый статический родитель λ₃·W₃ = 2m·W₃ ≠ 0 при m ≠ 0. Проверка нулеимпульсного предела провалена.
2. **Цветовой тип.** Все каналы несут коммутаторный цвет C; опоры C и d **дизъюнктны**: supp C = 116 троек (106 TTG + 10 GGG), supp C ∩ supp d = ∅ (0 троек из 13 244). GGG-сектор W₃ (28 троек) недостижим ни при каком импульсе — достижимы лишь 10 посторонних GGG-троек.
3. **Симметрия.** Полностью симметризованная цветовая часть всех каналов тождественно нулевая; W₃ полностью симметричен по цвету — никакое импульсное одевание не содержит W₃-компоненту.

**Синтез.** Локальный сектор исчерпан исчерпывающим списком: центральный чётный фон — единственный (Пакет 1), нецентральные нечётные фоны — no-go A (база (6)), производные кубические вершины — STOP (Пакет 2). Следовательно, **K₆(0) = λ₃·W₃ = 2μ·W₃ — нередуцируемо нелокальное данное**. Остаётся ровно два честных хода фронтира: (а) спецификация нелокального шеститочечного ядра K₆(k) с K₆(0) = 2m·W₃ и проверкой действительности/аналитичности; (б) официальное принятие λ₃ = 2μ как именованного данного фронтира — абсолютной единицы, структурно совпадающей с открытым масштабом времени временной ветви. Выбор — за A (запросы в §6).

## 2. Пакет 1 (B-A-04): метрическая единственность центрального фона

### 2.1 Постановка

Предыдущий гейт закрыл нецентральные нечётные фоны: их кубическая опора TTT + TGG не пересекает каноническую опору TTG + GGG тензора d_abc. Оставался чётный side: какие фоны вообще допускаются метрическим переносом главы полево-шумового отображения (гл. 82) и фиксированной алгеброй наблюдаемых. Пакет B-A-04 отвечает: в классе (P1)–(P3) — только центральный сдвиг.

### 2.2 Посылки

- **(P1)** родитель есть единая положительная норма сдвинутой кривизны R(Z) = MZ + ZM + Z², сохраняющая вакуум (R(0) = 0); кубическая вершина равна 2·Tr(MZ³);
- **(P2)** перенос метрики (гейт полево-шумового отображения, гл. 82) фиксирует квадратичную часть родителя с точностью до общего масштаба: q_M(Z) := Tr((MZ + ZM)²) = μ²·Tr(Z²) на всём 42-мерном центрированном пространстве флуктуаций;
- **(P3)** сохранение вакуумной структуры: фон лежит в централизаторе фиксированной алгебры наблюдаемых M₁₁⊕M₁₀ и не смешивает её представление. Это конститутивное требование неизменности пары «фиксированная алгебра, вес KMS», на которой стоит весь том.

### 2.3 Структурная чётность

Нечётные направления переноса чисто межблочные, чётные калибровочные — блочно-диагональные: Γ·F̂ₐ·Γ = −F̂ₐ при a < 30 (30 transfer), Γ·F̂ₐ·Γ = +F̂ₐ при a ≥ 30 (12 gauge). Для общей блочной формы отсюда тождественно Tr(O(E₁E₂+E₂E₁)) = 0 и Tr(O₁O₂O₃) = 0: симметричная кубическая форма кадра **не имеет каналов TTT и TGG**; полный пересчёт воспроизводит опору **140 TTG + 28 GGG**. Все нормы направлений ненулевые.

### 2.4 Теорема централизатора

Централизатор алгебры M₁₁⊕M₁₀ в M₂₁ равен span(I₁₁⊕0, 0⊕I₁₀), то есть M = m₁·I₁₁⊕m₀·I₁₀. Блочные коммутанты одномерны: любые внутриблочные решения пропорциональны единичной матрице блока. Тем самым (P3) сводит фон к двум скалярам (m₁, m₀).

### 2.5 Метрические условия и единственность

Подстановка M = m₁I₁₁⊕m₀I₁₀ в q_M = μ²Tr(Z²) даёт **42 точных полиномиальных условия** в поле Q(m₁, m₀, μ):

- **Нечётные направления:** 30 одинаковых факторов **(m₁ + m₀)² = μ²** — каждый нечётный элемент умножается фоном на единое число m₁ + m₀;
- **Чётные направления:** точное блочно-весовое тождество **4m₁²·W₁ᵏ + 4m₀²·W₀ᵏ = μ²·(W₁ᵏ + W₀ᵏ)**, где W_•ᵏ = Tr(F̂ₖ²|_•) — блочные следовые квадраты k-го калибровочного элемента.

При (m₁, m₀) = ((εμ + d)/2, (εμ − d)/2) каждое чётное условие факторизуется:

  **d·(2εμ·(W₁ᵏ − W₀ᵏ) + d·(W₁ᵏ + W₀ᵏ)) = 0,  d = m₁ − m₀.**

Двенадцать чётных элементов дают ровно **три различных весовых отношения** (W₁ − W₀)/(W₁ + W₀) ∈ {0, 2/3, −866/2457}. Ветвь d ≠ 0 потребовала бы d = −2εμ·rₖ одновременно для трёх различных rₖ — **невозможно при μ ≠ 0**. Значит d = 0, m₁ = m₀ = εμ/2. При μ = 0 нечётное условие даёт m₁ = −m₀, а чётные условия 4m₁²(W₁+W₀) = 0 с ненулевыми суммами коллапсируют в M = 0 (без нарушения чётности). Конкурирующий градуировочный фон M = (μ/2)Γ нарушает **все 30 нечётных условий**.

**Теорема (метрическая единственность центрального фона).** В классе посылок (P1)–(P3) решение 42 метрических условий в (m₁, m₀, μ) исчерпывается семейством **M = ±(μ/2)·I₂₁**, то есть (m₁, m₀, μ) = (t/2, t/2, ±t). Знак — ориентация кубической вершины λ₃ = 2μ. Единственный остаточный freedom — один скалярный масштаб μ.

### 2.6 Полнота классификации и nogocriterion

**Теорема (полнота классификации фонов).** Вместе с запретом нецентральных нечётных фонов предыдущего гейта классификация однофоновых сдвинутых кривизн **полна**: единственным допустимым источником нарушения чётности является центральный фон M = (μ/2)I₂₁, живущий в вычтенном при центрировании следовом направлении. Кубическая проекция на d_abc исчерпывается вершиной **2μ·d_abc**; на эталонном луче A = F̂₀ + F̂₄₀ воспроизводится действие **R(t) = 38μ²t² − 6μt³ + 134t⁴** — моменты (38, −3, 134) совпадают с лучом базы (6) точно (машинная проверка: Tr A² = 38, Tr A³ = −3, Tr A⁴ = 134).

**Nogocriterion (запрет присвоения масштаба).** Равенство M = (μ/2)I₂₁ нельзя объявлять выводом масштаба λ₃: теорема фиксирует форму фона, а не число μ. Абсолютный масштаб остаётся внешним для центрированных данных кадра; он совпадает по структуре с открытым абсолютным масштабом времени временной ветви.

### 2.7 Границы (честно)

- **Без (P3)** метрическое условие само по себе не определяет фон: линеаризованная система в v_ij = (m_i + m_j)² − μ² имеет ранг 21 (ядро 210), а носители кадра покрывают лишь 72 из 231 пары индексов.
- Одна калибровочная ковариантность тоже недостаточна: коммутант концевой калибровочной алгебры тринадцатимерен (6 + 7).
- Якобиан 42 условий в центральном решении имеет ранг 17 в полном пространстве фонов: **центральное решение не изолировано вне централизатора**.
- Единственность доказана только в классе (P3); сама посылка (P3) — конститутивное требование тома (неизменность пары «фиксированная алгебра, вес KMS»). Просим A подтвердить этот статус (§6, запрос 3).

## 3. Пакет 2 (B-GATE-DERIV-01): STOP производной ветви

### 3.1 Инвентаризация производных кубических каналов

Полная инвентаризация кубических каналов нормы Tr(R_m(F)\*R_m(F)) с R_m(Z) = mZ + Z²:

| Канал | Сектор | Цвет | Статус |
|---|---|---|---|
| 2⟨dA, A²⟩, A² = [A, A] для 1-формы | GGG | коммутаторный (C) | допущен |
| 2⟨dΦ, [A, Φ]⟩ | TTG | U = −C₍abg₎ (коммутаторный) | допущен |
| 2m⟨dA, dΦ·dΦ⟩ (m-взвешенный) | TTG | коммутаторный (C) | допущен |
| 2⟨dA, Φ²⟩ | — | — | **исключён** из формулировки границы в обоих прочтениях: Ходж-степень 2 + D − 0! ≠ D, либо нарушение калибровочной ковариации (d\*A)Φ² |

**Ключевое следствие:** все допустимые каналы несут **коммутаторный цвет C**; канала d-типа (полностью симметричного) не существует ни одного. Тем самым вопрос гейта свёлся к точному сравнению опор и характеров тензоров d и C.

### 3.2 Вычислительный протокол

- **Перебор:** все **13 244** неубывающие тройки a ≤ b ≤ c из 42 направлений; **0 Float** во всём аудите.
- **Кадр:** импортирован **напрямую из модуля базы** `s2t.proofdsl.examples.version8_full_noise_trace_frame` (42 = 30 нечётных transfer + 12 чётных gauge на C²¹, Γ = I₁₁⊕(−I₁₀)) — извлечение скриптов из Markdown не требуется (реализация урока 1 рецензии A, §5).

### 3.5 Вердикт гейта: три независимых режущих факта

**Факт 1 — нулеимпульсный предел.** Каждый допустимый канал содержит ровно один оператор производной d, поэтому вся производная кубическая вершина линейна по импульсу и её шеститочечное ядро удовлетворяет **K₆(0) = 0**. Требуемый статический родитель λ₃·W₃ = 2m·W₃ **не равен 0** при m ≠ 0. Проверка нулеимпульсного предела — **провалена**.

**Факт 2 — цветовой тип и дизъюнктность опор.** Коммутаторный цвет C не может одеть d-тип: опоры дизъюнктны, следовательно **GGG-сектор W₃ (28 троек) недостижим ни при каком импульсе** (достижимы лишь 10 посторонних GGG-троек из supp C), и TTG-пересечение также пусто. Никакое импульсное одевание коммутаторных каналов не воспроизводит опору 140 TTG + 28 GGG.

**Факт 3 — симметрия.** Полностью симметризованная цветовая часть всех каналов тождественно нулевая (Sym_abc Tr(F_x[F_y, F_z]) = 0 — проверено точно на случайных троках с фиксированным seed 20260830 и следует из тождества коммутатора); W₃ полностью симметричен по цвету. **Никакое импульсное одевание не содержит W₃-компоненту.**

Три факта независимы: каждый по отдельности запрещает производное происхождение λ₃·W₃. Вердикт: **STOP производной ветви** — честная остановка в смысле протокола.

## 4. Синтез: состояние фронтира после двух атак

### 4.1 Локальный сектор исчерпан

Исчерпывающий список локальных источников λ₃·W₃ и их статус:

| Источник | Статус | Откуда |
|---|---|---|
| Центральный чётный фон M = ±(μ/2)I₂₁ | **единственный допустимый** | Пакет 1 (B-A-04) |
| Нецентральные нечётные фоны | **no-go** (опора TTT+TGG не пересекает TTG+GGG) | база (6), гейт A |
| Производные кубические вершины | **STOP** (три режущих факта §3.5) | Пакет 2 (B-GATE-DERIV-01) |
| Новый постоянный коэффициент при W₃ | **запрещён** записью границы `noncentral_odd_no_go` | база (6) |

### 4.2 Следствие: K₆(0) — нередуцируемо нелокальное данное

Из таблицы §4.1 следует: значение **K₆(0) = λ₃·W₃ = 2μ·W₃** не может быть порождено никаким локальным механизмом. Допущенная алгебраическая форма **λ₃ = 2m, λ₃²/(αβ) = 4** (при m = μ — по теореме единственности фона M = ±(μ/2)I₂₁) обязана войти в нулеимпульсное значение нелокального ядра. **Новых констант не вводится.**

### 4.3 Ровно два оставшихся хода

**Ход (а) — нелокальная ветвь.** Спецификация нелокального шеститочечного ядра K₆(k) с точным нулеимпульсным значением **K₆(0) = 2m·W₃** и проверкой действительности/аналитичности в k = 0. Требования к классу ядер (предлагаем зафиксировать в вердикте A): действительность, аналитичность в нуле, ковариационные свойства кадра; проверка — рациональное тождество K₆(0) = 2m·W₃.

**Ход (б) — именованное данное.** Официальное принятие **λ₃ = 2μ** как именованного данного фронтира: абсолютная единица, структурно совпадающая с открытым абсолютным масштабом времени временной ветви. Тогда гейт закрывается формулировкой именованного данного, и барионный пакет переходит в состояние «λ₃ — внешняя абсолютная единица» (ровно тот же статус, что у масштаба времени; см. nogocriterion §2.6).

В обоих ходах значение самого μ остаётся внешним (nogocriterion): классификация фиксирует форму и структуру, но не число. Это не дефект поставки, а зафиксированная граница применимости центрированных данных кадра.

### 4.4 Что это даёт Задаче №1

До атак: λ₃-вопрос был открыт в обе стороны (производная ветвь или нелокальная ветвь — без критериев выбора). После атак: производная ветвь **закрыта теоремным no-go** (три независимых режущих факта), происхождение λ₃ сведено к **единственной структурной форме λ₃ = 2μ на единственном центральном фоне**, а фронтир сузился до дилеммы «нелокальная спецификация K₆(k) или именованное данное». Впервые в истории фронтира выбор формализован до двух взаимно исчерпывающих ходов.
