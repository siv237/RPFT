## 1. Главный результат: точка (24.7) расшифрована в ℚ(x) — все шесть весов

Канонический Casimir Тома VIII в порядке (L, SU(3), SU(2), U(1), QLYR, XLdR) печатает
ненормированные веса (0.83698439, 10.88079708, 4.81111832, 4.52410355, 5.44039854,
5.44039854). Все шесть чисел — **точные формы пакета Б** при x = e⁻², порог печатной
точности 5·10⁻⁹:

| семейство | точная форма в ℚ(x) | значение при x = e⁻² | печатное А | |Δ| | чтение в пакете Б |
|---|---|---|---|---|---|
| L | (10x+11)/(13(x+1)) = 1/(13·AB) | 0.836984390614 | 0.83698439 | 6.1·10⁻¹⁰ | link-вес (13 рёбер A₀) |
| SU(3) | (10x+11)/(x+1) = 1/AB | 10.8807970780 | 10.88079708 | 2.0·10⁻⁹ | 1/Tr(ρ·g₃²) |
| SU(2) | (20x+22)/(x+5) | 4.81111832082 | 4.81111832 | 8.2·10⁻¹⁰ | 1/Tr(ρ·g₂²) |
| U(1) | (60x+66)/(25x+13) | 4.52410354761 | 4.52410355 | 2.4·10⁻⁹ | 1/Tr(ρ·g₁²) |
| QLYR | (10x+11)/(2(x+1)) = 1/(2·AB) | 5.44039853899 | 5.44039854 | 1.0·10⁻⁹ | 2 × arrow-fwd вес |
| XLdR | (10x+11)/(2(x+1)) | 5.44039853899 | 5.44039854 | 1.0·10⁻⁹ | (на Q_L³ не действует) |

Здесь AB := (1+x)/(11+10x). Дополнительно доказано тождество в ℚ(x):
**1/gg (нормировки каналов пакета) == канонические gauge-веса (SU3, SU2, U1) — True**.

### Что это означает

1. **Рамки совпали, а не просто согласованы.** Нормировка каналов пакета Б
   w = 1/Tr(ρ_N g²) воспроизводит канонический Casimir KMS-Gram Тома VIII с точностью
   печатных 8 знаков по **всем шести** семействам, включая transfer. Общая фактор-структура
   всех шести форм — один KMS-знаменатель (11+10x) — показывает, что обе конструкции
   нормируются одним и тем же состоянием ρ_N (гл. 18) и, по-видимому, являются одной
   конструкцией, увиденной с двух сторон: А — через ортонормировку 19-мерного шумового
   quotient, Б — через поканальные зарядовые нормировки на Q_L³.
2. **Ветвь та же.** Тм 25.1: точка (24.7) канонична на стабилизаторной ветви (фиксированный
   вакуум A₀). Пакет Б живёт на фиксированной A₀-конструкции (13 рёбер) — та же ветвь.
   Критерий 25.1 (не объявлять веса полностью gauge-ковариантными до выбора вакуума)
   соблюдён автоматически.
3. **Числа «одиннадцать» и «тринадцать» из Т8 гл. 2 получают барионное эхо:** канонический
   вес link-семейства — это в точности 1/(13·AB), где 13 — число рёбер канонической A₀
   пакета; K = (11+10x)/(1+x) = 1/AB несёт размерности углов 11 и 10.

## 2. Судьба остатка 8,21 %: три новых точных утверждения

Базовая регрессия: val(w̄) = split/(3r₁) = 104(25x²+38x+13)/(425x³+6038x²+13689x+5564)
= **0.256960942726**, структура двух уровней сохранена, r₁ = 18.7231501791 — всё
воспроизведено против certificate_ab02.json.

### 2.1 Утверждение о каноничности значения

Gauge-сектор точки w̄ **канонически фиксирован** (§1, тождество). Следовательно,
0.256960942726 — значение дискриминатора в точке конуса, чья gauge-часть совпадает с
каноническим Casimirом Тома VIII. Остаток 1 − val/target = **8,21 %** (target = 293.1/(3·349.0),
ВНЕШНЕЕ СРАВНЕНИЕ) — это остаток канонической точки, а не произвольной калибровки.
Его уже нельзя списать на «удобный выбор нормировок» Б: нормировки продиктованы кадром ρ_N
и воспроизводятся независимой конструкцией А.

### 2.2 Невозможность блочного закрытия: G_η-срез (25.5)

Вдоль семейства метрик G_η = η·P_tr + P_gauge (Т8 (25.5)) — переносимый в мои
мультипликаторы как {arrow: η, link: η, gauge: 1} — дискриминатор:

val_η(η) = 104(25x²+38x+13)/(425η·x³ + 2346η·x² + 1105η·x + 3692x² + 12584x + 5564).

Точное решение val_η(η) = target даёт **η* = −2.1928… < 0 — вне конуса**. Более того,
sup по допустимому срезу sup_{η>0} val_η = lim_{η→0+} = **0.263742325124 < target = 0.27994269**.

**Вывод (точный): остаток 8,21 % НЕзакрываем transfer/gauge-блочным ребалансом** —
мишень лежит вне диапазона всего однопараметрического семейства (25.5) при η > 0.
Это первое содержательное «не может» о форме остатка: дело не в общем масштабе
transfer-шума относительно gauge-шума.

### 2.3 Закрываемость семейство-специфичной перебалансировкой: su2-срез

Вдоль su2-интенсивности t (остальные = 1):

val_su2(t) = 104·t·(25x²+38x+13)/(1950t·x² + 2964t·x + 1014t + 425x³ + 4088x² + 10725x + 4550).

Точное решение val_su2(t) = target: **t\* = 1.11320491255004** (контроль: val(t\*) = target).
Остаток 8,21 % закрывается повышением интенсивности su2-семейства ровно на **+11,32 %**
от канонической. Это фальсифицируемое предсказание для полной gauge-ветви (27-мерный
noise quotient, Т8 §25.3): если её Casimir сдвинет κ_SU2/κ_U(1) примерно на 11 %, остаток
исчезнет; если нет — residual 8,21 % устойчив к полному gauge-замыканию.

### 2.4 Чувствительность к ветвевой конвенции transfer (открытый вопрос)

Если перенести канонические transfer-веса в Q_L³-машинерию «fwd-чтением»
(m_arrow = κ_Q/(x/(4AB)) = 2/x, m_link = κ_L/(x/(13AB)) = 1/x), то r₁ = 24.5191206505 и
val = **0.196219040209** (остаток 29,9 %). Чувствительность к десятичным (24.7) как точным:
0.196219040206 — согласие 3·10⁻¹¹, т.е. закрытые формы верны. Разброс 0.1962 vs 0.2570 —
это цена **неопределённости ветвевой/мультиплисити-конвенции** переноса (κ_Q = 2×arrow-fwd,
κ_L = 1×link-fwd; вопрос, как Gram-ортонормировка 19-модуля комбинирует пары V, V*, —
внутреннее знание конструкции А). Вопрос зафиксирован в §4; до ответа А каноническим
чтением для барионного дискриминатора остаётся собственная adj-ветвь пакета (w̄).

## 3. Обновлённый статус no-go

```
CANONICAL_POINT_RESIDUAL_8.21_PCT:
  val = 0.256960942726 в точке w̄, чей gauge-сектор = канонический Casimir (24.7) Т8
  (идентификация ≤ 2.4e-9, тождество 1/gg == kappa_gauge доказано в Q(x));
  остаток 8.21% относительно fit-мишени (ВНЕШНЕЕ СРАВНЕНИЕ);
  НЕзакрываем блочным ребалансом G_eta (25.5): sup_{eta>0} val = 0.26374 < target (точно);
  закрываем su2-специфичной интенсивностью t* = 1.11320491255004 (точная кривая);
  наводка w* = 0.021120 против щели (24.5) = 0.0207491297 (+1.79%, p = 0.12) —
  теперь это сверка с щелью Канонического генератора А (L_can, гл. 24).
```

Итог по научному смыслу: «8,21 %» превратились из численной невязки в **структурный
объект** — число с доказанной каноничностью gauge-сектора, доказанной недостижимостью
по одному естественному направлению конуса и точной калибровочной кривой по другому.
Это ровно тот формат «фальсифицируемого наводящего остатка», который протокол слияния
(A→B/01) признаёт валидным.
