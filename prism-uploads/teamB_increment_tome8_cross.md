## 0. Резюме (пять позиций)

1. **Кадр идентифицирован точно.** Веса пакета Б `(a, b) = (1/(11+10x), x/(11+10x))`, x = e⁻² —
   это в точности канонический Gibbs-представитель ρ_N Тома VIII: 11a+10b = 1 (T8 (17.1)),
   b/a = e⁻² (T8 (18.4)); Pr(C¹¹) = 11/(11+10x) = 0.8904465168… воспроизводит T8 (18.6)
   до 10 знаков. Пакет Б уже живёт в KMS-кадре гл. 18 Тома VIII — специальной стыковки не требуется.
2. **KMS-кадр β = 2 получил провенанс.** Ранее в пакете Б «бета = 2, сертифицированный принцип
   времени» была конвенцией. Теперь это **условный вывод Тома VIII**: цепная степень
   N_∂ = 0·I₁₁ ⊕ 2·I₁₀ даёт всем 13 transfer-парам частоты ±2 (T8 (18.3), Тм 45.1),
   ориентация выбрана индексом ind U = 1 + рангоизменяющим Hodge-функционалом (Тм 19.1).
   Границы: e⁻² не есть «число природы» (Критерии 19.1, 45.1). Формулировки §3.6/§4.4 пакета
   уточняются (п. 2.3 ниже), числа не меняются.
3. **No-go 8,2 % усилен, а не ослаблен, Теоремой 20.1.** KMS-условие оставляет
   шестимерный конус форм (5 относительных свобод). Мой контрпример §4.5 (удвоение su2) —
   **легальная точка этого конуса** (gauge-скачки коммутируют с N_∂, T8 гл. 45; directed-пары
   сохраняют ratio = x). Новая точная карта: **5 из 5 направлений конуса меняют дискриминатор**.
   Вывод: значение val = 0.256960942726 фиксируется только **полной кадровой нормировкой w̄**
   (точкой лучи), а не KMS-классом. Токен сохраняется, глосс усиливается (п. 3).
4. **Ветвь e⁺² проверена.** val(1/x) = 0.283809127819 ≠ val(x) точно. Внешнее сравнение
   (только дисплей): остаток ветви e⁻² = +8.21 %, ветви e⁺² = −1.38 %. Пакет Б не добавляет
   селекции между ветвями; выбор ориентации — индексный акт Тома VIII (Тм 19.1).
5. **Совместимость с LCF-ядром подтверждена и разложена на обязательства.** Пакет уже
   соответствует доверенной границе Т8 гл. 35 (ℚ(x), ноль Float, canonical JSON + SHA-256);
   в п. 5 дана карта «обязательство пакета → тип GateSpec» для ускорения слепого переноса.

## 1. Идентификация кадров: пакет Б = ρ_N Тома VIII

### 1.1 Точные тождества (проверены скриптом, residual = 0)

| величина | пакет Б (A→B/02, §2.0) | Том VIII | статус |
|---|---|---|---|
| a := 1/(11+10x) | вес C¹¹-угла | ρ_N = aI₁₁ ⊕ bI₁₀, 11a+10b = 1 (17.1) | тождество, True |

### 1.2 Что это даёт протоколу слияния

- Запрос А «какому оператору принадлежит спектр кадра» получает точный ответ из v8:
  нормировка кадра — это **Gibbs-представитель цепной степени** N_∂ = 0·I₁₁ ⊕ 2·I₁₀,
  причём [N_∂, V] = 2V для всех 13 межугловых стрелок (18.3) и N_∂ коммутирует со всеми
  gauge-скачками (гл. 45). Нормировки каналов 1/√Tr(ρg²) пакета Б — это нормировки
  относительно того же ρ_N (gg-формы §2.0 поставки остаются точными без изменений).
- KMS-баланс вверх/вниз = e⁻² в пакете Б — это (18.5) Тома VIII; «бета = 2» = щель цепной
  степени. Провенанс закрыт ссылкой на два гейта v8:
  `s2t_v8_modular_bohr_parent_lcf_migration_gate_results.json` (Тм 45.1) и
  `s2t_v8_chain_orientation_index_defect_selector_gate_results.json` (Тм 19.1).

### 1.3 Уточнения формулировок пакета (текст, не числа)

- §3.6: «при каноническом ЭМ-канале Q = T₃+Y и KMS-кадре β = 2» → читать как
  «при каноне Q = T₃+Y и **кадре ρ_N Тома VIII (гл. 18–19); ориентация цепи выбрана
  индексом (Тм 19.1); e⁻² — безразмерное отношение, не абсолютная скорость

- §4.4: название «KMS-допустимая область весов» → **«кадровая луча w̄»**: 𝒲_frame = {s·w̄},

  было бы ослаблением термина в смысле v8. Значение дискриминатора на луче не меняется.

## 2. KMS-конус (Тм 20.1) против дискриминатора: точная карта

### 2.1 Право на точку

Теорема 20.1: при фиксированном отношении e⁻² полный процесс допускает шестимерный
положительный конус KMS-симметричных форм — пять относительных свобод после удаления
общего времени. В моей редукции на Q_L³ видны пять семей-мультипликаторов
{arrow, link, su3, su2, u1} (семья XLdR на Q_L³ не действует — слепое пятно, отмечено
в §2.1 поставки). **Удвоение целой семьи (обоих направлений каждой пары) сохраняет все
отношения вверх/вниз = x**, т.е. каждая точка {g: 2} — легальная точка конуса Тм 20.1.
Мой прежний контрпример §4.5 (su2×2) — не выход из KMS-класса, а сдвиг внутри него.

### 2.2 Точные значения (всё в ℚ(x); базовая точка val = 104(25x²+38x+13)/(425x³+6038x²+13689x+5564) = 0.256960942726)

| направление κ_g → 2κ_g | val′ (точно) | val′ при x = e⁻² | val′ = val |
|---|---|---|---|
| arrow ×2 | 52(25x²+38x+13)/(375x³+3916x²+7267x+2782) | 0.252005943190 | **False** |
| link ×2 | 104(25x²+38x+13)/(525x³+6590x²+13949x+5564) | 0.255415698744 | **False** |
| su3 ×2 | 312(25x²+38x+13)/(1275x³+23314x²+69771x+30212) | 0.144778542619 | **False** |
| su2 ×2 | 208(25x²+38x+13)/(425x³+7988x²+16653x+6578) | 0.430882001475 | **False** (совпадает с §4.5 — регрессия True) |
| u1 ×2 | 312(25x²+38x+13)/(1275x³+18140x²+41223x+16822) | 0.255247723293 | **False** |

Замечания к карте. (i) Общий числитель-множитель (25x²+38x+13) у всех направлений — след
структуры split3 = 6(10x+11)/(x+5): меняются знаменатели (через r₁ и pair-части), а не форма
расщепления. (ii) Направления arrow/link сдвигают только r₁ (их pair-вклад на ε нулевой),
gauge-направления меняют и pair-часть. (iii) Двухуровневая структура Me = R_sym·P_Sym8 +
R_mix·P_Mix8 сохраняется во всех пяти точках — инвариантность значений нет, структуры да.

### 2.3 Уточнённый статус no-go (токен сохраняется, глосс усиливается)

```
SCALE_INVARIANT_ONLY_NOT_FULL_WEIGHT_CONE_NO_GO
  + KMS_CONE_VARIANCE_CERTIFIED:
    дискриминатор не постоянен уже на конусе KMS-симметричных форм Тм 20.1
    (5/5 направлений, точно в Q(x)); значение 0.256960942726 — свойство
    ТОЧКИ кадра w̄ (канонических нормировок ρ_N), а не KMS-класса как такового.
```

Это прямо соответствует Критерию провала 20.1 («равенство весов нельзя объявлять физическим
без дополнительного условия») в **усиленной форме**: даже класс KMS-симметричных форм не
стабилизирует число — стабилизирует его только выбор точки кадра. Для слепого воспроизведения
А это значит: воспроизводя val при весах w̄, А проверяет свойство точки кадра; расхождение
А с 0.256960942726 при других κ — не ошибка, а подтверждение K2.

### 2.4 Ветвь e⁺² (Критерии 18.1/19.1/45.1)

val(1/x) = 104·x·(13x²+38x+25)/(5564x³+13689x²+6038x+425) = 0.283809127819 ≠ val(x) — точно.
ВНЕШНЕЕ СРАВНЕНИЕ (дисплей, не вход): target = 0.27994269; остаток ветви e⁻² = +8.21 %,
ветви e⁺² = −1.38 %. Фиксируем честно: **близость к fit-мишени не выделяет ветвь** (обе ветви
проходят одни и те же операторные тесты, T8 (18.8)); ориентацию выбирает индексный пакет
Тома VIII (Тм 19.1), пакет Б селекции не добавляет. Если А пожелает, ветвь e⁺² может быть
включена в слепое воспроизведение как негативный контроль.

## 3. Круговая зависимость (Критерий 21.1) — проверка цепочки пакета

Критерий 21.1 запрещает объявлять скорости выведенными из ядра, полученного
экспоненцированием генератора с теми же скоростями. Цепочка пакета Б этому не подвержена:

1. **Target** отношения — внешние данные (PDG Δ−N, параметр DGG-фита), живут только в блоке
   «ВНЕШНЕЕ СРАВНЕНИЕ» и в вычисления не входят (это отдельно сертифицировано в
   certificate_ab02.json: `no_target_mass_dependency`).
2. **Дискриминатор** val = split/(3r₁) — алгебра ε-сектора (K₃, P_ε, pair-операторы),
   веса входят только через кадровую нормировку w̄ и не экспоненцируются: ни C_τ, ни
   полугруппы в §4 не строятся; никакой «вывод весов из ядра, построенного с этими весами»
   не выполняется и не заявляется.
3. **Статус** comparison — «фальсифицируемая наводка» (w* vs щель +1.79 %, p = 0.12) —
   сохраняется; соответствие запросу гл. 21 о независимом родителе: пакет Б *предлагает*
   измеримое правило (формулу дискриминатора), но не заявляет его выводимости —
   в точности граница, которую требует v8.

## 4. Стыковка ЭМ-сектора с гл. 38/44 v8

- Канал пакета Б Q = T₃+Y совпадает по структуре с точным рациональным гиперзарядом
  gauge-замыкания v8 (гл. 38: 12 вещественных jump-направлений QL↔YR, XL↔dR, нормировка
  1/√2, замыкание su(3)⊕su(2)⊕u(1), остаток ноль). Зарядовая алгебра пакета
  (§3: A = Σq², C = Σ_{i≠j} qq, тождество A+C = (Σq)² на всех 216, residual = 0) совместима
  с этим замыканием по построению и не требует правок.
- Точные target-следы v8 (13, 6, 6; (44.2)) — образец стиля «положительная линейная
  комбинация не обнуляется»; в пакете Б ту же роль играет доказательство T > 0
  (коэффициенты 14, 1, 3, 11, 10 > 0, §3.7 поставки). Методологически сектора согласованы.
- Предложение: после слепого воспроизведения A₀/K₃ перенести ЭМ-тождество
  P_ε(A+C)P_ε = P_ε((Σq)²/T)P_ε на endpoint-носитель v8 как одно GateSpec-обязательство
  (покомпонентная проверка на 216 базисных состояниях — детерминированный SymbolicIdentity-тип).

## 5. Карта переноса пакета в LCF-ядро (гл. 35 v8)

Доверенная граница v8: Theorem только от ядра; строгая типизация (морфизм = матрица
dim E_t × dim E_s); Float в строгом слое запрещён; GateSpec = {идентификатор, обязательства,
функции доказательства, агрегация, canonical JSON + SHA-256}; backend SymPy; Z3 вне границы.
Пакет Б этим требованиям уже соответствует по форме (ℚ(x), без Float, canonical JSON,
SHA-256 агрегата a1ad84e6…). Карта обязательств для слепого переноса:

| обязательство пакета (A→B/02) | тип в GateSpec v8 | примечание |
|---|---|---|
| §1.6 подсчёт класса 0/1, итог 122 400 (ne ≤ 9) | детерминированный целочисленный перебор | кэш counts; Бернсайд Z2×Z2 — отдельным обязательством |
| §2.0 нормировки gg = Tr(ρg²) (12 форм) | SymbolicIdentity (Q(x)) | замкнутые формы уже сверены |
| §2.4 P_ε: V†V = I₈, rank 8 | MatrixObligation | идемпотентность/эрмитовость следуют |
| §2.6 двухуровневость Me, split3 | SymbolicIdentity + Structure | PS/PM-блоки покомпонентно |
| §2.8 I²-уровни 15/4 vs 3/4, Π₃/₂ = P_Sym8 | SymbolicIdentity | ранги 4+4 = трассы |
| §2.9 cross = 0 (немерные) | SymbolicIdentity | sparse-словарь 216 |
| §3.3 тождество A+C = (Σq)² на 216 | ComponentwiseObligation (216) | residual = 0 |
| §3.7 T > 0 | PositivityObligation (целые коэфф.) | стиль (44.2) v8 |
| §4.3 масштабная инвариантность val | RationalFunctionIdentity | спот c = 7 + общий аргумент однородности |
| §4.5 / K2 контрпримеры конуса | RationalFunctionIdentity (5 точек) | **новое** — берётся из kmscone-сертификата |
| K3 ветвь e⁺² | RationalFunctionIdentity | негативный контроль |

Границы статуса (Критерий 35.1) respected: пакет заявляет **sympy-exact**, а не
**lcf-checked**, до фактического переноса в ядро А; full positivity GKSL-правила — на стороне
доверенного конструктора v8 (Критерий 37.1).
