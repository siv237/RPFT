# Version IV: bounded Gram endpoint gate

## Вопрос

Спасает ли канонический bounded transform

\[
b(Q)=Q(1+Q^2)^{-1/2}
\]

прямой Gram-eigenvector endpoint?

## Результат

- Mass-selected scale: `368.4287`.
- Maximum mass error: `85.46`.
- Cabibbo angle: `0.01248`.
- `|J_q| = 1.12e-15`.

## Вердикт

Нет. Bounded transform ещё сильнее сжимает sector differences и усиливает
light-family degeneracy. Произвольные nonlinear spectral functions после
этого не допускаются; новый map должен быть stationary solution parent action.
