# Version IV.SM Variational Family State Gate

The graph partial trace defines a family operator and the state is varied over
all positive trace-one density matrices. The quadratic moment is degenerate.
At fourth order the plus branch has ground value about 12.608881, below the
minus value about 13.225083. The ground state is unique, not the odd-corner
state, and the sixth-moment stress test selects the same branch.

The Yukawa readout and physical CKM phase remain open.
