# Affine modular temperature

Parent operator стандартизован по среднему и spectral standard deviation.
Это делает Gibbs state инвариантным относительно `R -> aR+bI` и выводит
effective temperature без mass fit.

Лучший KMS branch даёт `s12 = 0.270`, то есть всего в 1.20 раза выше CKM
target. Максимальная mass error снижается до 69. Однако `s23`, `s13` и CP
остаются подавленными.

Получен второй partial pass: modular dynamics правильно локализует Cabibbo
plane, но одного moment constraint недостаточно для полного flavour sector.
