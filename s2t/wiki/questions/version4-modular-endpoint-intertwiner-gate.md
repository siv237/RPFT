# Modular endpoint intertwiner gate

Из нормированного Casimir-family operator построено Gibbs state
`rho_s = exp(-Rhat_s) / Tr exp(-Rhat_s)`. Endpoint edges взвешены через
`sqrt(rho_s)` в left, right и KMS-symmetric placements.

Это впервые меняет leading metric: `L L† = 2 rho_s`, поэтому universal
bounded-propagator no-go действительно обходится. Лучший KMS branch даёт
`s12 = 0.1419`, но middle-family masses, остальные CKM angles и Jarlskog
остаются слишком малы.

Ветка является partial structural pass, но physical fail. Следующий шаг
требует вывести modular temperature из boundary dynamics, а не fit-ить её.
