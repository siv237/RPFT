# Version IV.SM Cross-Sector Transposition Orbit Gate

## Relative Pair Classification

The stabilizer of the rank-one projector acts transitively on the four
single-sector transposition minima. The twelve ordered distinct up/down pairs
form three relative orbits.

The cross word Tr(P_minus H_u H_d) takes the values minus one half, zero and
plus one half and distinguishes all three relative classes.

## Selector Status

Separate up and down square actions contain no mixed closed path, so they do
not generate the cross word. Adding its coefficient by hand would select a
class but would not be a derivation.

## Minimal Readout

For Y_s=P_minus+i H_s, every class has mass-squared spectrum
{1/2,1,5/2}. All commutator-cube CP invariants vanish, and every class has a
large off-diagonal mixing entry. Thus the unit-amplitude branch is not a
physical blind output.
