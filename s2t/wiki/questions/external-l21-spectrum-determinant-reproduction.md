# Независимое воспроизведение спектров и детерминантов на L(2,1)

> Статус: первый внешний gate пройден частично
> Дата: 2026-08-03
> Машинный результат: `external_l21_spectrum_determinant_reproduction_results.json`

## Цель

Проверить независимо от внутренних численных совпадений:

1. скалярный спектр на `L(2,1)=RP^3`;
2. коэкзактный спектр одних форм;
3. соглашение `det'` для скалярной нулевой моды;
4. структуру Maxwell--ghost determinant;
5. применимость опубликованных lens-space determinant формул к нетвистованному Maxwell-сектору.

## Внешние опоры

- Ikeda--Yamamoto задают классическую спектральную теорию трёхмерных lens spaces.
- Lauret формулирует Hodge--Laplace spectrum quotient-пространства через инвариантные подпространства представлений.
- Nash--O'Connor вычисляют детерминанты нулевых и первых форм на lens spaces, включая `p=2`.
- Dowker даёт независимое численное значение минимального скалярного детерминанта на projective three-space.
- Современная формула gauge-fixed `p`-form partition function выражает Maxwell sector через transverse/coexact determinant и скалярный determinant без zero mode.

## Спектр без скручивания

Для стандартного Maxwell-поля используется тривиальное плоское расслоение. Усреднение character по группе `Z_2` даёт:

```text
scalar:   n even, lambda=n(n+2), multiplicity=(n+1)^2;
coexact1: n odd,  lambda=(n+1)^2, multiplicity=2n(n+2).
```

Первые скалярные multiplicities равны

```text
1, 0, 9, 0, 25, ...
```

а первые коэкзактные multiplicities:

```text
6, 0, 30, 0, 70, ...
```

Они полностью совпадают с внутренней таблицей проекта. Следовательно, оболочки `n=1` и `n=3` с размерностями `6` и `30` подтверждены внешней representation-theoretic схемой.

## Проверка скалярного детерминанта

После удаления постоянной моды скалярная zeta-функция имеет спектр

```text
lambda_m=4m(m+1), multiplicity=(2m+1)^2, m>=1.
```

Независимое продолжение даёт

```text
zeta'_0(0) = -0.6951703617566010.
```

Dowker сообщает для projective three-space значение `-0.695171`. Абсолютное различие составляет около `6.38e-7`, то есть опубликованное число воспроизведено в пределах округления.

## Коэкзактный determinant

Для нетвистованных коэкзактных одних форм:

```text
lambda_m=4m^2, multiplicity=8m^2-2, m>=1,
zeta'_coex(0)=2 log(pi)-4 zeta(3)/pi^2
              =1.8022844587645080.
```

При этом `zeta_0(0)=-1`, `zeta_coex(0)=1`, а полный one-form sector имеет `zeta_1(0)=0`, как требует Hodge decomposition на нечётномерном замкнутом многообразии с `b_1=0`.

## Важное различие twisted/untwisted

Формулы Nash--O'Connor для `p=2` включают нетривиальный character плоского расслоения. Он меняет parity selection: twisted и untwisted spectrum оставляют противоположные оболочки. Поэтому их готовые `p=2` determinant-числа нельзя непосредственно подставлять в стандартный Maxwell sector проекта. Они используются только как контроль метода регуляризации.

## Maxwell--ghost вывод

В нетвистованной схеме выполняется

```text
log det' Delta_1 = log det Delta_1^coex + log det' Delta_0.
```

Отсюда стандартный FP functional содержит

```text
Gamma_nonzero = 1/2 log det Delta_1^coex
                - 1/2 log det' Delta_0.
```

То есть внешний расчёт независимо подтверждает скалярный half-determinant residual. Он не создаёт компенсацию, необходимую для восстановления точного `pi^-4`.

## Влияние на перспективность

- Спектральная основа lens-space части теории становится сильнее.
- Внутренние multiplicity tables подтверждены независимо.
- Ранее вынесенный отрицательный verdict по `C6` не отменяется, а усиливается.

- Перспективность дальнейшей внешней проверки сохраняется: следующий содержательный объект --- полный determinant на `RP^3 x S^1`, включая Matsubara/winding decomposition.
