# Version IV.SM Yukawa Operator Map Gate

The variationally selected family state admits several basis-covariant,
coefficient-free Yukawa maps. The baseline map is CP-zero, while the
state-anticommutator map has a nonzero cubic commutator invariant. The
quartic cotangent gradient produces a hierarchy but remains CP-zero and has
large mixing. Thus CP generation is algebraically possible, but the same
geometric data do not select a unique physical map or distinguish all four
observed Yukawa edge types.
