\section*{Проверка квантованного импульсного сектора ротора}

Восемь вещественных вращательных плоскостей с единичным голономным весом
дают точный логарифмический коэффициент (8/3). Независимый перебор
фиксированных целочисленных импульсов проверяет условие
\[
 \sum_{i=1}^{8}p_i^2=48,
\]
необходимое для коэффициента (8/(1-c)) при нормированном следе ранга (3).
Среди положительных нечётных импульсов существуют две ветви. Однако при
минимально возможном максимальном импульсе (p_{\max}=3) решение единственно:
\[
 (p_1,\ldots,p_8)=(1,1,1,3,3,3,3,3).
\]
Оно сохраняет знак минус при полуповороте и точно воспроизводит обратный
член. Невыведенным остаётся динамический выбор этого сектора исходным
действием.
