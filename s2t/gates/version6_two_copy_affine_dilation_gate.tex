\chapter{Двухкопийная дилатация квадратной обратной связи}

Предыдущая проверка нашла осесвободный усилитель
\begin{equation}
 \mathcal P(R)=\frac{R^2}{\Tr(R^2)},
 \label{eq:v6-two-copy-square-map}
\end{equation}
но одновременно доказал, что он нелинеен по состоянию. Теперь необходимо
проверить, снимает ли это препятствие уже существующий тензорный квадрат
носитель, или он даёт только виртуальное чтение нелинейной величины.

\section{Точная двухкопийная формула}

Пусть $\Sigma$ --- оператор перестановки двух копий семейного пространства.
Для любого наблюдаемого $O$ выполняются тождества
\begin{align}
 \Tr\bigl[(O\otimes I)\Sigma(R\otimes R)\bigr]&=\Tr(OR^2),\\
 \Tr\bigl[\Sigma(R\otimes R)\bigr]&=\Tr(R^2).
 \label{eq:v6-two-copy-swap-identities}
\end{align}
Следовательно, отношение двух двухкопийных средних точно равно
\begin{equation}
 \frac{\Tr\bigl[(O\otimes I)\Sigma(R\otimes R)\bigr]}
      {\Tr\bigl[\Sigma(R\otimes R)\bigr]}
 =\Tr\bigl(O\mathcal P(R)\bigr).
 \label{eq:v6-two-copy-virtual-state}
\end{equation}
На ста случайных вещественных состояниях численный остаток этого тождества
не превысил $4.5\cdot10^{-16}$.

Это именно механизм virtual distillation: несколько копий позволяют
вычислять наблюдаемые состояния $R^M/\Tr(R^M)$, не приготавливая это
состояние как выход детерминированного канала. См.
\path{arXiv:2011.07064}, DOI
\path{10.1103/PhysRevX.11.041036} и DOI
\path{10.1103/PhysRevX.11.031057}.

\section{Почему нормировка не становится линейной динамикой}

Рассмотрим одноосное семейство
\begin{equation}
 R(t)=\operatorname{diag}\left(t,\frac{1-t}{2},\frac{1-t}{2}\right).
\end{equation}
Матрица $R(t)\otimes R(t)$ полиномиальна по $t$ степени не выше двух.
Поэтому выход любого фиксированного линейного канала на двух копиях также
полиномиален степени не выше двух. Но первая компонента
\eqref{eq:v6-two-copy-square-map} равна
\begin{equation}
 p(t)=\frac{t^2}{t^2+(1-t)^2/2},
 \end{equation}
то есть является неполиномиальной рациональной функцией. На сетке
$t\in[0.05,0.95]$ её наилучшее квадратичное приближение оставляет
максимальный остаток $0.14517\ldots$.

\begin{theorem}[Граница двухкопийной дилатации]
Носитель тензорного квадрата и оператор перестановки точно воспроизводят все
средние виртуального состояния $R^2/\Tr(R^2)$. Однако никакой один
фиксированный линейный следосохраняющий канал на $R\otimes R$ не имеет это
нормированное состояние своим выходом для всех $R$.
\end{theorem}

Физическое обновление требует дополнительного инструмента: выведенной
постселекционной ветви, измерения с обратной связью, большей унитарной
дилатации с записью результата или контролируемого mean-field предела.
Ни один из этих элементов текущим родителем пока не выбран.

\section{Что это меняет для программы}

Отрицательный результат не отменяет фазовый функционал. Член
$2e_2(R)$ был получен непосредственно из нормированного внешнего носителя,
а не из фиктивного физического приготовления $R^2/\Tr(R^2)$. Поэтому
статическая упорядоченная фаза и её спинодальная граница сохраняются.

Закрывается только более сильное утверждение: квадратичная обратная связь пока
нельзя считать автономным законом движения. Вместо дальнейшего
конструирования ложной нелинейной квантовой карты можно перейти к
линеаризации уже выведенной упорядоченной фазы и установить, какие поля и
топологические сектора она действительно содержит.

\begin{nogocriterion}[Виртуальное состояние не является новым вакуумом]
Совпадение всех отношений многокопийных наблюдаемых с
$R^2/\Tr(R^2)$ не доказывает физического приготовления этого состояния и
не задаёт автономной эволюции.
\end{nogocriterion}

\begin{protocol}
\begin{enumerate}
 \item двухкопийное SWAP-тождество: \textbf{точно};
 \item максимальный машинный остаток: \textbf{$4.5\cdot10^{-16}$};
 \item виртуальные средние $R^2/\Tr(R^2)$: \textbf{доступны};
 \item детерминированный линейный канал: \textbf{невозможен};
 \item физическая постселекционная ветвь: \textbf{не выведена};
 \item фазовый функционал $2e_2(R)$: \textbf{сохраняется};
 \item следующая проверка: \textbf{спектр поля проекторного параметра порядка};
 \item рождение материи: \textbf{не закрыто}.
\end{enumerate}
\end{protocol}
