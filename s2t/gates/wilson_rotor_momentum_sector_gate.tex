\chapter{Восстановленный quantized rotor momentum gate}

Восемь вещественных вращательных плоскостей с единичным голономным весом
дают точный логарифмический коэффициент (8/3). Независимый перебор
фиксированных целочисленных импульсов проверяет условие
\[
 \sum_{i=1}^{8}p_i^2=48,
\]
необходимое для коэффициента (8/(1-c)) при нормированном следе ранга (3).
Среди положительных нечётных импульсов существуют две ветви. Однако при
минимально возможном максимальном импульсе \(p_{\max}=3\) решение единственно:
\[
 (p_1,\ldots,p_8)=(1,1,1,3,3,3,3,3).
\]
Оно сохраняет знак минус при полуповороте и точно воспроизводит обратный
член. Вместе с determinant восьми unit-weight planes получаем
\[
 \Gamma_{\rm rotor}(c)
 =\frac8{1-c}+\frac83\log(1-c),
\]
то есть оба нелинейных коэффициента возникают без непрерывной подгонки.

Этот результат был потерян из активной карты после технического отката
рабочей оболочки и теперь восстановлен. Его статус --- exact operator-level
identity, но не физическое предсказание: невыведенным остаётся динамический
выбор fixed-charge ensemble и именно этой odd momentum branch исходным
действием.
