\chapter{Запрет стационарного гамильтониана на минимальном двухцепочечном носителе}
\label{ch:v8-static-local-hamiltonian-embedding-no-go-gate}

Индексно-сбалансированный конвейер имеет GNVW-индекс $1$ и допускает
точную двухстадийную локальную реализацию. Теперь проверяется более сильное
требование: существует ли один трансляционно-инвариантный конечнодальний
гамильтониан $H_{\rm stat}$ на тех же двух цепях, для которого
\begin{equation}
 e^{-i\tau H_{\rm stat}}=W_1W_0.
\end{equation}
Первый строгий тест проводится в минимальном физически естественном классе:
$H_{\rm stat}$ сохраняет число возбуждений вспомогательных систем и не содержит
дополнительного регистра часов.

\section{Блох-представитель встречного потока}

В одночастичном секторе две цепи дают двухкомпонентный Блох-носитель. Его
точный шаг равен
\begin{equation}
 U(k)=\begin{pmatrix}e^{-ik}&0\\0&e^{ik}\end{pmatrix},
 \qquad k\in[-\pi,\pi].
\end{equation}
Числа намотки собственных каналов вычисляются без численной аппроксимации:
\begin{align}
 \nu_A&=\frac1{2\pi i}\int_{-\pi}^{\pi}
  (e^{-ik})^{-1}\partial_k e^{-ik}\,dk=-1,\\
 \nu_B&=\frac1{2\pi i}\int_{-\pi}^{\pi}
  (e^{ik})^{-1}\partial_k e^{ik}\,dk=+1.
\end{align}
Их сумма равна нулю, что согласуется с тривиальным полным индексом, но
каждый собственный канал имеет ненулевое число намотки.

\section{Запрет периодического статического логарифма}

Конечнодальний трансляционно-инвариантный гамильтониан, сохраняющий число, задаёт
непрерывную периодическую самосопряжённую матрицу $h(k)$, являющуюся
тригонометрическим полиномом. Если
\begin{equation}
 e^{-i\tau h(k)}=U(k),
\end{equation}
то $h(k)$ коммутирует с собственной экспонентой. При
$k\not\equiv0,\pi$ матрица $U(k)$ имеет два различных собственных значения,
поэтому $h(k)$ диагональна в фиксированных каналах $A,B$. Каждая диагональ
должна быть непрерывным периодическим скалярным логарифмом соответствующей
фазы.

Но экспонента периодической функции имеет нулевое число намотки:
\begin{equation}
 \frac1{2\pi i}\int_{-\pi}^{\pi}
 e^{i\tau h_A(k)}\partial_k e^{-i\tau h_A(k)}\,dk
 =-\frac{\tau}{2\pi}\bigl(h_A(\pi)-h_A(-\pi)\bigr)=0.
\end{equation}
Это противоречит $\nu_A=-1$; второй канал независимо даёт противоречие
с $\nu_B=+1$.

\begin{theorem}[Минимальный статический запрет]
Не существует трансляционно-инвариантного конечнодальнего гамильтониана,
сохраняющего число, на минимальном двухцепочечном носителе, точная экспонента
которого за конечное время равна встречному сдвиговому конвейеру $W_1W_0$.
\end{theorem}

\begin{remark}[Почему индекс $1$ был недостаточен]
GNVW-индекс видит суммарный перенос алгебры через разрез и потому допускает
сокращение $-1+1=0$. Статический Блох-логарифм должен дополнительно
разрешить число намотки каждого невырожденного собственного канала; на минимальном
носителе это невозможно.
\end{remark}

\begin{nogocriterion}[Область запрета]
Доказательство использует трансляционную инвариантность, конечную дальность,
сохранение числа возбуждений и отсутствие дополнительных часовых степеней
свободы. Оно не исключает взаимодействующий гамильтониан на расширенном
носителе или автономные часы Фейнмана--Китаева. Такие стационарные
гамильтоновы квантовые клеточные автоматы известны как общий вычислительный
механизм; см. \path{arXiv:0802.0886}. Но их точное однотактовое возвращение
к нашему $\Phi_h$ требует отдельного доказательства.
\end{nogocriterion}

\begin{protocol}
\begin{enumerate}
 \item полный GNVW-индекс: \textbf{$1$};
 \item числа намотки собственных каналов: \textbf{$(-1,+1)$};
 \item число намотки определителя: \textbf{$0$};
 \item минимальный носитель: \textbf{две $43$-мерные цепи};
 \item трансляционная инвариантность: \textbf{предполагается};
 \item конечная дальность: \textbf{предполагается};
 \item сохранение числа: \textbf{предполагается};
 \item непрерывный периодический статический логарифм: \textbf{нет};
 \item кусочно-заданный локальный гамильтониан Флоке: \textbf{сохраняется};
 \item общий взаимодействующий стационарный гамильтониан: \textbf{не исключён};
 \item расширение часами: \textbf{не проверено};
 \item следующий гейт: \textbf{стационарный гамильтониан конвейера с расширением часами}.
\end{enumerate}
\end{protocol}
