\chapter{Точный LCF-запрет нетривиального KMS-селектора}
\label{ch:v8-kms-nontracial-relative-rate-lcf-migration-gate}

Скалярная неподвижная алгебра полного унитального примитивного процесса
принуждает единственное нормированное стационарное состояние
\begin{equation}
 \rho_*=I_{21}/21.
\end{equation}
Поэтому центральное состояние $aI_{11}\oplus bI_{10}$ стационарно лишь при
$a=b=1/21$. Численный перебор отношения $b/a$ заменён этим точным следствием.

Обход положительными весами невозможен: точные целевые следы связывающих, QLYR-
и XLdR-переносов равны соответственно $13,6,6$, так что
\begin{equation}
 13\kappa_L+6\kappa_Q+6\kappa_X>0
\end{equation}
для всех положительных коэффициентов.

Для $H_\Delta=\Delta P_{10}$ тринадцать скачков переноса точно распадаются
на пары $V,V^*$ с частотами $\pm\Delta$. Самосопряжённый $V+V^*$ не является
одной ненулевой боровской модой. Направленная модель дала бы только условие
\begin{equation}
 \gamma_\uparrow/\gamma_\downarrow=e^{-\beta\Delta},
\end{equation}
но $\beta\Delta$ родителем не выведено.

\begin{theorem}
Текущий полный QMS допускает только следовое KMS-состояние и не выбирает
относительные скорости.
\end{theorem}
\begin{nogocriterion}
Нельзя считать $e^{-\beta\Delta}$ предсказанием до независимого вывода
модульного гамильтониана и направленного разбиения скачков.
\end{nogocriterion}
\begin{protocol}
\begin{enumerate}
\item единственное состояние: \textbf{$I_{21}/21$};
\item положительные следы переноса: \textbf{$13,6,6$};
\item боровских пар: \textbf{$13$};
\item KMS-отношение: \textbf{условное};
\item селекция скоростей: \textbf{не получена}.
\end{enumerate}
\end{protocol}
