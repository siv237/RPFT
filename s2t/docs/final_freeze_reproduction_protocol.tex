\section{Протокол воспроизведения}

Frozen package делится на модули геометрии, спектров, zeta/heat-kernel,
Gram/projector identities, \(B-L\) anomalies и no-go map. Экспериментальные
данные не входят в математический пакет. Численные expected outputs должны
быть запечатаны до фиксации независимой реализации.

Обязательны два уровня проверки:
\begin{enumerate}
 \item \emph{computational reproduction}: новая реализация без использования
 внутренних скриптов проекта;
 \item \emph{mathematical replication}: независимая проверка аналитических
 доказательств, областей операторов, кратностей и схем регуляризации.
\end{enumerate}

Машиночитаемый пакет расположен в каталоге
\texttt{s2t/reproduction\_package/}. Любое изменение frozen-файлов создаёт новую
версию пакета и не изменяет задним числом статус II.A/II.B.
